# Ally Support

Monsterfish · 1.0.19

Les alliés de l’IA partagent les stocks en gardant de quoi couvrir leurs besoins.

L’IA peut demander et partager de l’or tout en gardant une réserve pour le recrutement.

Les alliés peuvent envoyer des troupes, garder une réserve et ouvrir leurs portes aux visiteurs.
